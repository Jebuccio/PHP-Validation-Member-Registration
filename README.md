# Member Registration Lab — Starter

1. Open a terminal inside this folder and start the PHP development server:

       php -S localhost:8000

   then open `http://localhost:8000`. Keep the terminal open (requests and PHP errors appear there);
   press Ctrl+C to stop it. `php -m` must list `fileinfo`.
2. Search the project for `TODO` — there are 25, numbered in the order you should do them:
   - `includes/validation.php` — TODO 1-13 (regular expressions and validation)
   - `register.php` — TODO 14-16 (saving the uploaded photo)
   - `profile.php` — TODO 17-23 (rendering the member card)
   - `css/style.css` — TODO 24-25 (styling the member card)
3. Follow the activity handout for the exact input formats and the test cases.

Right now the form accepts anything, even a blank submission. That is expected until you finish Part A and B.
